# 📜 MultiLog
**MultiLog** is a mod that automatically creates separate log files for each player.

**Useful for players who frequently change nicknames and want to keep their logs separated.**

---

## Download
The latest and most stable versions of the mod are always available on the official page:
* **[Download the mod on Modrinth](https://modrinth.com/mod/multilog)**
* **[Download the mod on CurseForge](https://www.curseforge.com/minecraft/mc-mods/multilog)**

## 🐛 Found a bug or have an idea?? / Issues
If you encounter issues, the game crashes, or you want to suggest a new feature:
1. Go to the tab **[Issues](https://github.com/KurguzMe/MultiLog/issues)** at the top of this page.
2. Click the button **New Issue**.
3. Select the appropriate template (Bug Report) and fill out the form following the instructions.

*You can also attach log files (`latest.log`) when reporting game crashes!*
